## 真实测试发现与修复

1. **类型错误**：CLI 原先固定创建 ConnectorPlugin，实际编辑器进入连接类设计流程。补充 `create --type other` 后真实回读类型为空，显示前端扩展配置。首次误建草稿已明确标记，未发布、未安装、未删除。
2. **草稿限制**：已有开发中 0.0.1 时平台拒绝另建版本，说明只允许一个开发中版本。完成发布后才创建下一版本。
3. **容器名**：实际 UUID 派生名称以数字开头，webpack 默认 var 导出失败。改用 window 属性库，保留原容器名。
4. **发布配置**：extensionInfo 写成数组时，保存成功但官方发布报 fastjson 类型错误。官方编辑器回读证实应为 `{extensionIds: [...]}`；CLI 修复结构、保留其他元数据并核对该字段后发布成功。
5. **组件声明**：运行态扩展必须配置 `config.componentNameList: ["OpenYidaStickyTimeline"]`。缺失检查、示例和 Skill 已补齐。
6. **面板识别**：压缩后的函数缺 displayName，真实设计器未登记组件。0.0.3 显式设置 `OpenYidaStickyTimeline` 后，面板出现组件并可拖入。
7. **吸顶边界**：某预览宿主的中间祖先有 overflow:hidden，阻断原生 sticky。0.0.4 在此情况按实际滚动容器计算位移，并将日期与目录限制在组件自身范围；没有修改宿主全局 overflow。正常宿主继续使用原生 sticky。

历史 0.0.1、0.0.3 产物保存在 releases，后续部署保留旧路径。源码版本、资源版本、组织发布与消费者执行分别留证；配置保存或注册候选可见不能替代真实页面验收。
